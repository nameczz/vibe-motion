# Vibe Motion Skills Showcase v4 Claude Typer Trial

The current visual composition for the 12 selected Skill segments, using the
real remote `claude-typer` composition for every invocation. Final voice and
music assembly remains separate.

## Editorial contract

- 1920x1080, 30fps, H.264 visual-only output.
- A 300-frame opening presents all 12 selected Skills as an animated,
  two-column capability matrix using the official Vibe Motion avatar.
- The opening contains visual-only Chinese subtitle placeholders for the two
  approved narration lines. There is no redundant count summary at the end of
  the opening.
- Every invocation slot uses an actual ProRes 4444 video generated by
  `~/.codex/skills/claude-typer/scripts/render_claude_typer.py`
  against `https://www.laosunwendao.com` / `Typer30fps`.
- The project wrapper `scripts/render-claude-typer-v4.py` delegates to that
  exact Skill script and only overrides its exposed `model` prop to
  `Vibe Motion`; the remote template title remains `Claude Code`.
- Generated prompts follow `调用 <slug>：<Chinese capability summary>` and use
  30ms typing speed at 1920x1080 with a 1500px Claude window.
- Invocation slots keep their original durations by applying a deterministic
  playback-rate fit. Every effect animation keeps its complete frame count.
- `02-brand-launch-video-star` and `04-disney-animation-rule-skill` remain
  excluded; standalone source `03-claude-typer` is removed from the film and is
  only used as the invocation generator.
- On-screen badges are continuous `01` through `12`; original source numbers
  remain in staging and provenance paths.
- `12` remains the approved monochrome-blue Liang progression meme, contained
  at its native square aspect ratio without cropping.
- Skill slugs appear as persistent `slug · SKILL` overlays during effects.
- No TTS or final soundtrack is embedded in the v4 visual master. ChatCut is not
  modified by this workflow.
- `07` is locked to SHA-256
  `9aa89e4b571721db10a1d3da2e18157bc501f6a1ac650b78e1f81662f02f7d78`.

## Commands

```bash
pnpm run showcase:prepare
pnpm run showcase:invocations:v4
pnpm run showcase:manifest
pnpm run showcase:timeline
node "${BRAND_LAUNCH_VIDEO_STAR_SKILL_DIR:-$HOME/.codex/skills/brand-launch-video-star}/scripts/validate-assets.mjs" showcase/asset-manifest.json
node "${BRAND_LAUNCH_VIDEO_STAR_SKILL_DIR:-$HOME/.codex/skills/brand-launch-video-star}/scripts/validate-timeline.mjs" showcase/timeline.json
pnpm run showcase:compositions
pnpm run showcase:review-frames
pnpm run showcase:render:v4-claude-typer-visual
pnpm run showcase:contact-sheet:v4-claude-typer-visual
pnpm run showcase:verify
```

`pnpm run showcase:render:v4-claude-typer-visual` is the one-command visual
release path. It prepares staging, verifies or renders all remote claude-typer
assets, regenerates provenance and timeline files, validates exact shot
coverage, renders to an isolated temporary file, verifies the silent media
contract, and atomically publishes
`out/VibeMotionSkillsShowcase-v4-claude-typer-visual.mp4`.

Generated invocation assets and their manifest live under
`public/showcase/v4-invocations/`. v4 outputs live under `out/` with explicit v4
names. The workflow writes only the explicit v4 output and does not overwrite
source Skill packages, effect sources, or the approved ruler source.
