# Short-form social packaging

## Deliverable shape

A strong short-form package usually contains a 3:4 or 9:16 vertical video, a real frame-zero cover, a clean loop or deliberate final hold, a short screen recording of the interactive hand-control version when available, and model/music attribution where required.

For a visual hook, start with the product large and recognizable, introduce one fast camera move, then show a readable rigid explosion. Hold the exploded state long enough to understand it before reversing. Use sound design—whoosh, servo tiers, low impact, magnetic lock—without burying the visual in music.

## Creator narrative

Prefer a factual process story: inspect a separable 3D model, group semantic parts, author assembled and exploded transforms, improve PBR materials and lighting, add reversible timing or gesture input, then verify and record.

If AI generated an art-direction frame but the motion is code-rendered, say so. A useful distinction is: “AI set the target look; the final separation and interaction run locally in code.”

Avoid claiming that a single flat image was reconstructed into physically correct hidden geometry. Avoid copying another creator's footage or generated transition.

## Publishing checklist

- Check the first frame as an extracted image.
- Verify resolution, fps, duration, and audio streams.
- Keep platform UI-safe margins around important details.
- Credit CC-BY assets in the post or end card.
- Keep the title outcome-led; put implementation details in the body.
- Include a simple prompt for comments only if it feels natural, such as asking what product to disassemble next.
